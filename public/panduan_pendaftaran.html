📋 Panduan Input Pendaftaran Pasien

🎯 Tujuan Sistem

Ketika Anda input pendaftaran pasien, sistem akan secara otomatis:

  • ✅ Simpan data ke database tabel pendaftaran
  • ✅ Generate nomor antrian unik
  • ✅ Kirim ke antrian kasir/admin
  • ✅ Kirim ke dokter yang bertugas
  • ✅ Track status: Menunggu → Sedang Dilayani → Selesai

🚀 STEP 1: Masuk ke Aplikasi

Login

  • Buka: http://localhost/PROJECT-KELOMPOK-3-KLINIK-NUSANTARA/
  • Username: sesuai user yang terdaftar
  • Password: sesuai password user
  • Pilih login sebagai: Petugas Pendaftaran atau Admin

🚀 STEP 2: Akses Menu Pendaftaran

Navigasi ke Form Pendaftaran

  • Di dashboard, cari menu "Pendaftaran"
  • Klik "Pendaftaran Poliklinik" atau "+ Pendaftaran Baru"
  • Akan muncul pilihan: Pasien Baru atau Pasien Lama

🚀 STEP 3: Input Data Pasien (Jika Pasien Baru)

Form Pasien Baru

Isi field berikut:

Nama Lengkap *: [Wajib diisi]
NIK *: [Wajib diisi, unik per pasien]
Jenis Kelamin *: Laki-laki / Perempuan
Tanggal Lahir *: [Format: YYYY-MM-DD]
Golongan Darah *: O / A / B / AB
Jenis Pasien *: Umum / Asuransi / BPJS
Agama *: [Pilih dari dropdown]
Pendidikan: [Optional]
Provinsi *: [Wajib diisi]
Alamat *: [Alamat lengkap]
Telepon: [Nomor HP/Telpon]
Pekerjaan: [Optional]

🚀 STEP 4: Pilih Poliklinik & Jadwal Dokter

Form Pendaftaran Poliklinik

Isi field berikut:

✳️ Poliklinik *: [WAJIB! Pilih Umum / Gigi / Kandungan]
✳️ Jadwal Dokter *: [WAJIB! Akan muncul setelah pilih Poliklinik]
✳️ Keluhan Utama *: [Jelaskan dengan detail apa yang dirasakan pasien]
✳️ Jenis Pembayaran *: [Umum / BPJS / Asuransi]
No BPJS/Asuransi: [Isi jika memilih BPJS/Asuransi]
✳️ Tanggal Kunjungan *: [Default hari ini, bisa diubah]
⚠️ PERHATIAN:
  • Gunakan tombol "Lanjut" di form, jangan refresh halaman!
  • Pastikan Poliklinik dipilih TERLEBIH DAHULU sebelum pilih Jadwal
  • Jika Jadwal tidak muncul, tunggu sebentar lalu refresh halaman
  • Pastikan semua field bertanda * sudah diisi!

🚀 STEP 5: Verifikasi Pendaftaran di Antrian

Melihat Pendaftaran di Antrian

  1. Setelah berhasil submit, akan redirect ke halaman konfirmasi
  2. Buka menu "Pendaftaran" → "Antrian Pasien"
  3. Cari nama pasien yang baru saja didaftarkan
  4. Status akan menunjukkan: Menunggu
✅ SUKSES!
Jika pendaftaran sudah terlihat di antrian dengan status "Menunggu", berarti sistem berfungsi dengan baik!

🚀 STEP 6: Dokter Melihat Antrian

Untuk Dokter / Perawat

  1. Login dengan akun Dokter
  2. Di Dashboard akan melihat counter: "Pasien Menunggu"
  3. Klik "Queue Pemeriksaan" atau "Examination"
  4. Akan melihat list pasien yang menunggu di poliklinik mereka
  5. Klik nama pasien untuk mulai pemeriksaan

❌ Jika Ada Masalah

Pendaftaran tidak muncul di antrian?
  • 1. Periksa console browser (F12 → Console tab) untuk error
  • 2. Pastikan form tidak ada yang kosong (lihat pesan error di form)
  • 3. Refresh halaman dan coba lagi
  • 4. Cek file storage/logs/laravel.log untuk error server
  • 5. Jalankan: php artisan config:clear di terminal

📊 Database Fields yang Disimpan

Ketika pendaftaran berhasil, database akan menyimpan:

pasien_id: ID pasien
poliklinik_id: ID poliklinik yang dipilih
jadwal_poli_id: ID jadwal dokter
nomor_antrian: 001, 002, 003, ... (auto-generated)
keluhan: Keluhan yang diinputkan
jenis_pembayaran: Umum / BPJS / Asuransi
no_bpjs: Nomor BPJS (jika ada)
tanggal_kunjungan: Tanggal kunjungan
status_layanan: "Menunggu" (awal) → "Sedang Dilayani" → "Selesai"
created_at: Waktu pembuatan
updated_at: Waktu update terakhir

💡 Tips

  • Setiap hari nomor antrian di-reset (dimulai dari 001)
  • Nomor antrian unik per poliklinik
  • Jika ada nomor antrian kembar, check di database
  • Status otomatis berubah saat dokter mulai pemeriksaan
  • Data tersimpan di tabel: pendaftaran, pasiens, polikliniks, dokters, jadwal_polis
